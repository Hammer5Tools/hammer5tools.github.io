# Installation & Setup

## Requirements

- Windows 10 or 11 (64-bit)
- Counter-Strike 2 Workshop Tools

## Install

1. Download the current installer from the [Hammer5Tools releases page](https://github.com/dertwist/Hammer5Tools/releases).
2. Run the installer.
3. Start Hammer5Tools from the Start menu.

If an installation location requires elevated permissions for file operations, run the affected operation with the permissions your environment requires.
