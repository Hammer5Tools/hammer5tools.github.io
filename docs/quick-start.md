# Quick Start

1. Install Hammer5Tools and configure the Counter-Strike 2 path in **Settings** if needed.
2. Select an addon.
3. Open the editor or utility appropriate for the asset you want to create.
4. Save the generated source file and review it in the relevant Source 2 tool.

For maps, use [Map Builder](#map-builder). For sound events, use [SoundEvent Editor](#sound-editor). For Source 2 detail props, use [DetailProp Editor](#detail-prop-editor).
